# Copy Language Policy — 한/영 혼용 규약

> ui.askewly.com 사이트 카피(그리고 Askewly Design 이 만드는 모든 사람-대면 산출물 카피)의 언어 선택 정본.
> 사용자 확정 2026-07-31: ko/en 분리(i18n 라우트) 대신 **한 사이트 안 혼용 정책**. 문체 = **해요체**.

## 원칙

한 문장으로: **UI 용어·고유명·코드·데모 콘텐츠는 영어, 사이트가 자기 목소리로 말하는 설명·안내는 한국어(해요체)로 씁니다.**

| 영어로 남기는 것 | 한국어로 쓰는 것 |
|---|---|
| UI 용어·패턴명 (accordion, bento grid, hero…) | 설명문·안내문 (섹션 소개, 페이지 인트로, 빈 상태 안내) |
| 제품·브랜드 고유명 (Askewly Design, Patterns, Docs, Colors, Recipes, Get Started) | CTA 의 동사부 ("Patterns 둘러보기") |
| 코드·토큰·파일 경로·단축키 표기 (`surface.muted`, `Ctrl F`, llms.txt) | 검색 입력창 힌트·툴팁·상태 메시지 |
| **데모 콘텐츠 내부 텍스트** — 예시 UI 가 표현하는 가상 제품의 문구(대시보드 라벨, 커머스 상품명, 마케팅 예시 헤드라인) | 사이트가 그 데모를 소개하는 문장 |
| 섹션 아이브로우(EYEBROW) 등 시각 장치로 쓰는 짧은 대문자 라벨 | 페이지 `<h1>`~`<h3>` 급 설명형 헤딩(용어 자체가 헤딩이면 영어 유지) |

## 문체

- **해요체**로 씁니다 — "패턴을 둘러보세요", "같은 토큰에서 출발해요". 합니다체·평서체(~다) 금지.
- em dash(—) 금지, 콤팩트하게(기존 Showcase 카피 규칙과 동일).
- **번역이 아니라 재작성**: 영어 원문을 직역하지 않고 같은 뜻을 한국어답게 다시 씁니다. "당신의", "~에 대한", "~를 통해" 같은 번역투 금지.
- 한국어 문장 안의 영어 명사는 조사 없이 어색하면 자연스러운 조사를 붙입니다 ("Patterns 를" → "Patterns를" 표기 통일: 붙여 씀).

## 표면 판정표 — 무엇이 "자기 목소리"인가

카피를 만나면 이 표로 판정합니다. 애매하면 "이 문장은 사이트가 방문자에게 하는 말인가(→한국어), 예시 화면이 자기 세계 안에서 하는 말인가(→영어)"를 묻습니다.

| 표면 | 판정 | 언어 |
|---|---|---|
| 랜딩 히어로 헤드라인·서브카피 | 자기 목소리 | 한국어 |
| 랜딩 섹션 헤딩·소개문·푸터 안내문 | 자기 목소리 | 한국어 |
| 쇼케이스·Atlas 카드의 용어 정의 카피 | 용어 정의(사전 콘텐츠) | 영어 유지 |
| 데모 카드 내부 (버튼 라벨, 표 데이터, 가상 브랜드명) | 데모 콘텐츠 | 영어 |
| topbar 내비 라벨 (Patterns, Docs, Colors…) | 고유명 | 영어 |
| 검색 입력창 힌트·결과 그룹 라벨·빈 결과 안내 | 자기 목소리 | 한국어 |
| docs 허브 그룹 설명·페이지 인트로 | 자기 목소리 | 한국어 |
| docs 아티클 본문 | 콘텐츠(별도 전환 배치) | 현행 유지 |
| 용어 상세 본문 (one-liner, description…) | 사전 콘텐츠(별도 전환 배치) | 현행 유지 |
| colors·recipes 페이지 인트로 | 자기 목소리 | 한국어 |
| Get Started 카드 제목 | 고유명(목적지 이름) | 영어(명사형) |
| Get Started 카드 설명·CTA | 자기 목소리 | 한국어 |
| 에러·로딩·빈 상태 메시지 | 자기 목소리 | 한국어 |
| SEO 메타(title·description) | 별도 판단 대기(검색 유입 언어 전략) | 현행 유지 |

## CTA 혼용 형태

목적지 고유명(영어)을 한국어 동사가 감싸는 형태를 기본으로 합니다.

- "Open Patterns" → "Patterns 둘러보기"
- "Open Docs" → "Docs 읽어보기"
- "Open Colors" → "Colors 살펴보기"
- "Open Recipe Gallery" → "Recipe Gallery 열기"
- 순수 행동 CTA 는 그냥 한국어: "Copy" → "복사", "Learn more" → "자세히 보기"

## 에이전트 계약

- 이 사이트(또는 Askewly Design 산하 산출물)의 카피를 새로 쓰거나 고칠 때, 이 문서의 판정표를 먼저 적용합니다.
- 데모 콘텐츠를 한국어로 바꾸지 않습니다. 자기 목소리를 영어로 새로 쓰지 않습니다.
- 판정표에 없는 새 표면을 만나면 원칙(자기 목소리인가?)으로 판정하고, 이 문서에 행을 추가해 판정을 남깁니다.
