# Landing Section Rhythm — 랜딩 섹션 리듬 (밴드 교차)

> 지위: 설명형 랜딩(제품·서비스 소개)의 섹션 시퀀스 판정 규칙. 출처 = upstage-sixsense(sixsense.askewly.com) 랜딩 실구현 채굴(harvest, 2026-08-04 — `research/2026-08-04-m22-harvest-mining-ledger.md` ⑬ 카드).

## 계약 — 배경 밴드가 리듬을 만든다

섹션 시퀀스는 내용 순서이자 **배경 톤의 교차**다. 실측 시퀀스:

```
히어로(기본 지면 + 인터랙티브 데모/증거 카운터)
→ band-warm  : 대비 카드 (문제 vs 해답 — contrast-duo-card)
→ band-ink   : 프로세스 스테퍼 (3단계 — 어두운 밴드가 "방법"을 분리)
→ band-warm  : 참여/제보 CTA
→ closing    : 예산 칩 등 마지막 행동 유도
→ footer
```

| 규칙 | 근거 |
|---|---|
| 인접 섹션은 배경 톤을 교차한다 (기본→warm→ink→warm→기본) | 스크롤 위치 감각 — 단색 연속이면 어디까지 읽었는지 사라진다 |
| 어두운 밴드(ink)는 1곳, "방법/프로세스"에 배정 | 가장 밀도 높은 정보에 가장 강한 분리 |
| 설명 블록 위계는 전 섹션 동일: muted 라벨 → 볼드 헤드라인 → 보조 설명 | 반복되는 위계가 리듬을 읽히게 한다 (contrast-duo-card 와 동일 원리) |
| 히어로에 실물 증거 1개(데모 카드·카운터)를 넣는다 | 주장보다 관측 — 첫 화면에서 제품이 움직이는 것을 보인다 |

## 판정 절차

랜딩 의뢰 시: ① 섹션 목록을 먼저 톤(기본/warm/ink)으로 배정 ② ink 1곳 초과면 재검토 ③ 설명 블록 위계 3단을 전 섹션에 강제. 조합 원리는 `research/2026-07-19-st4-composition-patterns.md`(순서·비중이 유형을 가른다)과 상보.
