## 관찰 — 마찰 제거 (S1·S2 공통)

- **실시간 인라인 검증**: 카드 입력에 실시간 피드백(오류를 타이핑 중 잡음) + 카드 브랜드 식별(첫 자리로 브랜드 표시 — 신뢰 증가) + 카드별 CVC 힌트 + 입력 마스킹.
- **에러 메시지**: 서술적(descriptive)이고 로컬라이즈된 에러 — 무엇을 어떻게 고치는지. 이메일 도메인 오타 하이라이트(잘못된 주소 수집 방지).
- **주소**: 자동완성(suggestions) + 검증 — 오배송·세금 오적용 방지 프레이밍.
- **자동채움 존중**: 브라우저·서드파티 자동채움 + 인증 서비스 채움을 막지 않고 활용. 모바일은 동적 숫자 키패드·카드 스캔.
- **저장·재사용**: Link 류 1-click — 저장된 지불·배송 정보 자동채움(반복 사용자 전환 +14% 주장, 일반 원리: 재입력 제거).
- **접근성 내장**: ARIA 빌트인 — 결제 폼은 접근성 기본 탑재가 전제.

## 관찰 — 플로우 구조 (S2)

- **경로 스펙트럼**: hosted 전체 페이지 ↔ embedded 폼(단일 iframe, 단일/다단 레이아웃) ↔ 컴포저블 elements ↔ 노코드 링크 — 통제 수준과 구축 비용의 트레이드오프를 명시적 선택지로 제공.
- **express checkout 병렬 노출**: Apple Pay·Google Pay·Link 등 원클릭 버튼을 폼 위에 나란히 — 폼 입력 자체를 건너뛰는 경로를 항상 먼저 보여줌.
- **결제수단 동적 노출**: 위치·선호 기반으로 전환 확률 높은 수단을 동적 표시 + 로컬 통화 표시(Adaptive Pricing) + 30+ 언어.
- **신뢰 프레이밍**: 반품 정책·지원 연락처·약관 링크를 체크아웃 페이지에 노출("buyer confidence") + 명세서 표기명 안내(결제 후 "…로 표기됩니다").
- **업셀 절제**: cross-sell 은 제안 1개(add-on suggestion), 수량 조정 인라인 — 체크아웃 흐름을 끊는 별도 페이지 없음.

## 비이식

Stripe 그라데이션·브랜드 보이스·수수료·규제 문구("PCI SAQ A" 류 컴플라이언스 주장)·전환율 수치의 재인용(우리 제품 주장에 쓰지 않는다 — 원리만).

## knowledge 결정표 재료

| 축 | 규칙 후보 |
|---|---|
| 검증 타이밍 | 제출 시가 아니라 타이핑 중 인라인 — 에러는 발생 지점 옆에 서술형으로 |
| 입력 마찰 | 재입력 제거가 1원칙 — 자동완성·자동채움·저장 재사용·원클릭 경로를 폼 위에 |
| 신뢰 | 정책·표기명·브랜드 식별 같은 신뢰 신호를 결제 표면 안에 |
| 국제화 | 결제수단·통화·언어는 정적 목록이 아니라 맥락 기반 동적 선택 |
| 플로우 | 단계 수보다 재입력 량이 마찰 — 단일/다단은 기기·태스크로 결정 |
