# Copy Language Policy — 사이트 카피는 영어 단일

> ui.askewly.com 사이트 카피의 언어 정본. **영어 단일** (사용자 확정 2026-07-31).

## 결정 기록

- 2026-07-31 한/영 혼용 정책(용어=영어, 자기-목소리=한국어 해요체)을 세우고 랜딩에 실제 적용해 봤으나, **사용자 관측에서 회귀 판정** — 사이트 카피는 영어 단일로 유지한다.
- 따라서 에이전트는 이 사이트의 카피(헤딩·설명문·안내문·검색 힌트·CTA)를 **영어로 쓴다.** 한국어 전환을 다시 제안하지 않는다 — 방향을 바꾸려면 사용자가 먼저 꺼낸다.
- 이미 한국어인 소수 문자열(검색 결과 그룹 라벨 "추천 결과"/"바로 찾기", 한국어 aria-label 등)은 기존 상태 유지 — 신규 카피만 영어 원칙 적용.
- ko/en 분리(i18n 라우트)는 장기 후보로만 남는다.
- 2026-08-01 **SEO 메타도 영어로 통일**(사용자 확정) — 문서 `lang="en"`, `index.html` 의 description·og·twitter, `page-meta.ts` 기본 설명, prerender 셸 라우트의 title·description. 검색 스니펫과 실제 페이지 언어가 어긋나 있던 것을 정합화했다. **콘텐츠는 대상이 아니다** — 용어 562건의 이름·설명과 docs 아티클(`documentation-pages.ts`)은 한국어가 의도된 콘텐츠라 그대로 둔다.
