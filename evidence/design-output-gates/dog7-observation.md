# DOG7 — 사람 관측 (부분 관측, 판정 미완)

Date: 2026-07-22
Status: **보류** — 관측 1회 실시, 사용자 판정 2건 중 **0건 획득**

## 관측 설계

DoD는 "사용자가 실제 디자인 작업 1건에서 새 마무리 절차를 겪고, 오탐이 성가신지와 차단 승격 가부를 발화로 답한다"였다. 사용자 발화로 관측 개시: "간단하게 테스트 디자인 작업해봐. 웹사이트 하나 만들어보던가".

- 과업: Askewly Design 랜딩 페이지 1장 (신규, DESIGN.md 없는 프로젝트)
- 매체: 화면 (N-0 판정)
- 산출물: `scratchpad/dog7-landing/` — `index.html` + `styles.css` + `tokens.css`(askewly 배포본)
- 절차: `/askewly-design` → llms.txt → entry-protocol → 압축 브리프 → recipe·anti-patterns·signature fetch → 구현 → `verify` → 실물 확인

## 실측 1 — 기계 검사는 통과했고, 아무것도 못 잡았다

```
$ npx @askewly/design@0.2.0 verify . --ext html,css
verify PASS — 2 file(s) scanned, no color literals and no file over 5 type sizes
```

수정 전후 2회 모두 PASS. **오탐 0건, 적발 0건.**

- 오탐 0: DOG1~DOG2의 오탐 교정(SVG 내부·주석)이 이 산출물에서는 걸릴 일이 없었다 — 해당 구조가 없었다.
- 적발 0: 문서를 먼저 읽고 쓴 코드라 색 리터럴이 애초에 0이었다. 토큰을 별도 `tokens.css` 파일로 분리해 검사 제외 대상에 태운 것도 작용했다.

**이 관측은 오탐률을 재지 못했다.** 위반이 한 건도 생기지 않은 산출물에 검사기를 돌린 것이므로, 분리력이 없는 케이스다(VL7의 96.9%가 VL8 결함을 구조상 못 쟀던 것과 동형).

## 실측 2 — 실제 결함 2건은 전부 검사기 사각지대에서 나왔다

| # | 결함 | 발견 경로 | 검사기가 못 보는 이유 |
|---|---|---|---|
| 1 | 워드마크가 **브라우저 기본 파란 링크**로 렌더 (`a`에 `color`·`text-decoration` 미지정) | 라이트 스크린샷 육안 | 색 리터럴이 아니라 **스타일 부재**다. 검사기는 있는 값만 세고 없는 선언은 못 센다 |
| 2 | 필터 빈 상태에서 행이 안 숨겨짐 (`display: grid`가 `hidden` 속성을 덮어씀) | 빈 상태 클릭 실행 | 기능 버그. 정적 검사·스크린샷 양쪽 다 못 잡고 **조작**해야 나온다 |

결함 1은 스타일 시그니처 비선호 5("대충 그린 CSS — 기본 브라우저 스타일 노출")의 하드 페일이다. 즉 **시그니처가 FAIL로 규정한 항목을 기계 게이트가 PASS로 통과시켰다.**

결함 2는 스크린샷만 첨부하고 넘어갔으면 남았을 결함이다. 프로토콜 5단계가 "스크린샷이 아니라 live 결과"를 요구하는 근거가 이번에도 실측으로 재확인됐다.

## 실측 3 — 브리프 단계가 사용자에게 보이지 않았다

압축 브리프 4문항(규모·소재·톤·산출물 위치)을 AskUserQuestion 1라운드로 제시했고 사용자는 전부 추천값을 선택했다. 그런데 직후 사용자 발화:

> "브리프 질문이 있었어?"

성가심은 관측되지 않았으나(1라운드·전부 추천 선택), **그 단계가 무엇을 하는 단계인지 사용자에게 전달되지 않았다.** 프로토콜상 신규 사이트의 정식 경로는 전략층 6문항 + 시각축 18종 Brief Studio이며, 이번엔 사용자 선택으로 4문항 압축본을 썼다.

## 실측 4 — 게이트 용어가 전달되지 않았다

"경고 → 차단 승격 가부"를 물었을 때 사용자 발화:

> "verify를 경고에서 차단이 뭔 소리야"

설명 후에도 판정은 나오지 않았다("됐어 뭔지 모르겠으니 넘어가고"). **질문 자체가 사용자 언어가 아니었다.** DoD가 요구한 판정 2건 중 어느 쪽도 획득하지 못했고, 그 원인은 사용자의 무관심이 아니라 질문 설계다 — 사용자가 답할 수 있는 형태로 묻지 못했다.

## 판정

- **오탐 성가심**: 미획득 (위반 0건이라 오탐이 발생할 수 없었음)
- **차단 승격 가부**: 미획득 (질문이 전달되지 않음)
- **게이트 현 상태**: **경고 유지.** 승격 근거 없음.

## 부활 조건

1. 실제 작업 1~2건에서 **verify가 실제로 위반을 뱉는** 케이스를 누적한다. 위반 0인 산출물로는 오탐률을 못 잰다.
2. 승격 질문을 사용자 언어로 다시 설계한다 — "차단/경고" 대신 "위반이 남았을 때 그냥 넘어가도 되게 할까, 못 넘어가게 할까" 수준.

- **기계 게이트가 시그니처 하드 페일을 통과시킨다.** 검사기는 "잘못 쓴 값"을 잡지만 "안 쓴 선언"(기본 브라우저 스타일 노출)은 못 잡는다. 검사 축 추가 후보: 스타일 없는 인터랙션 요소(`a`/`button`에 color·text-decoration·상태 미지정) 탐지.
