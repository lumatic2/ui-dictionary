## step-1 — 리디자인 시안 (사용자 선택 게이트)

시안 덱은 scratchpad 에서 실빌드·실렌더(목업 아님, validate 0 warning). 비교 시트: `img/dq3-시안-표지-3안.png`(현행·A·B) · `img/dq3-시안-수치장-2안.png`(현행·A/B 공통).

**공통 변경(A·B 동일) — 감사 미달 항 대응**
- 표지 문구(Q8): 제품명 "Askewly Design" → **"디자인이 매체마다 따로 논다"**(청중 문제로 훅), 제품명은 칩으로 강등.
- 수치 장(Q7·Q9·Q11): 4계열 4색 차트 → **제목이 결론("정본에 이미 562개 용어가 쌓여 있다")** + 단색 카드 3장으로 수치 격리. 4번째 항목(13)은 잘라 4개 상한·밀도 개선.

**A안** — 이미지 없음. 타이포·여백만으로 구성(현행 톤 유지).
**B안** — A안 + 표지 풀블리드 히어로 이미지. 이미지는 **생성(codex exec image_gen)** — 프롬프트는 imagery.md §3 템플릿(팔레트 hex 고정 cream #F4F3EE·ink #15130F·navy #2F4B7C, Constraints 줄 불변). 산출 1672×941(16:9 정합 — 치수 가드 통과), 글자·로고·얼굴 없음 육안 확인. 은유: 한 장의 정본이 여러 장으로 펼쳐지고 그중 하나가 네이비(강조)로 구분되는 종이 더미.
  - 관측된 다듬을 점(B 선택 시 처리): 제목이 이미지의 좌측 여백을 다 못 살리고 종이 위로 넘어가 대비가 아슬아슬 — 좌측 정렬 강화 또는 스크림 농도 조정 필요.

**부수 발견(수리 완료 아님, 기록)**: 커버 히어로 풀블리드는 캔버스 크기(1280×720) 뷰포트에서 정상 — 스크래치 캡처 스크립트가 1920×1080 고정이라 레터박스로 보였던 것. 캡처 스크립트에 캔버스 뷰포트 인자를 추가해 해소(스킬 코드 아님).
